# Contributing to Robin

Thanks for contributing to Robin!

## Development setup

1. Install a compatible Python version and Ollama.
2. Clone this repository.
3. Create and activate a virtual environment.
4. Install `requirements.txt`.
5. Download a supported local model.
6. Run `python -m robin.desktop`.

## Before submitting changes

- Run Python compilation checks.
- Run the relevant unit tests.
- Explain the changes and how they were tested.
- Never commit model weights, private conversations, credentials,
  or personal activity logs.

## Security

All computer-control tools must enforce Robin's independent
permission policy. Do not introduce silent destructive actions
or bypass the approval system.
